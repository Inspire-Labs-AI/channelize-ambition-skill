# channelize-ambition

## What is this

A skill that takes a goal — usually one line — and channels it into the single
highest-leverage direction, builds the domain expert's playbook, writes a full
expert-grade brief, then executes it.

## Why it matters

Left alone, work defaults to the median move: do what was literally asked, from
the material given, with the obvious method, and grade it yourself. That is
competent and forgettable. This skill forces the master's move instead — pick
the direction with the most leverage, work out how the best in the niche
actually do it, and execute to their standard.
